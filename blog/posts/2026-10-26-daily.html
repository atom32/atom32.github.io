今天能坐下来写的东西不多，但有一条挺具体：有人把旧 Kindle 的越狱交给了 Codex，从买线到刷完，全程只说了一句话。另一条更让人愣一下：睡前给 AI 排游戏开发任务，第二天早上，一个能跑的 3D 原型在等你。

二十块钱的线，和一句"帮我越狱"

教程短到不像教程。京东到家买一根绿联的 type-c 转 micro-usb 线，二十多块，一小时送到；插上 Kindle，用数据线连电脑，然后跟 Codex 说："帮我越狱 kindle"。

作者提到了一句要紧的话：如果模型拒绝，就换个模型接着问。这句被截断了，但意思够清楚。他还放出了开源地址，说明不是嘴上说说，真跑通了。

这类事情有意思的地方不在越狱。Kindle 越狱十几年了，论坛里的帖子能堆成山。变的是入口：以前你得知道自己要找什么、该刷哪个固件、卡在哪一步意味着什么。现在你知道"这件事可以问"就行。

门槛从技术挪到了信息。这话听着轻巧，其实挺重的。它意味着会做的人还是那批人，只是愿意动手的人会突然多出一大截。

睡觉的时候，别人在给你建模

开发者 Lucca Cerf 展示的流水线，据转述是这个样子：晚上把任务排给 AI，第二天醒来，一个能运行的 3D 游戏原型已经做好了。下面的评论区更值钱，他自己说了成本：Claude Max 20x 的周额度已经用掉了一大截。

同一个人另一条帖子把工序拆得更细。Flux 3 出角色概念图，Tripo 3.1 出高精度模型，Blender Agent 优化模型，然后自动绑骨骼、做动画，最后导进 Unreal。一条链下来，一个人做 3D 游戏，可能真的不需要自己捏角色了。

我对此的感觉是分裂的。被省掉的确实是苦活：拓扑、绑定、权重、K 帧，这些活折磨过每一个想独立做游戏的人。但"能跑的原型"和"能玩的游戏"之间隔着的那段路，一点没短。原型第二天早上就在那儿，好玩不玩，还是得你自己熬。

更微妙的是，同一天还有一条反方向的新闻：Gamers Club 说 vibe coding 游戏"死了，几乎"。理由是 Claude 和 ChatGPT 开始禁止复制现成的应用和游戏，也禁止逆向工程。

把这两条摆在一起看，边界正在往上移。工厂给了你，图纸不给你。你能一个人做出一个 3D 游戏，但"照着某个游戏做一个"这条路被收窄了。至于这条线画得对不对，我暂时没答案。

真正稀缺的不是模型，是把模型关进流程

有人推 BMAD-METHOD，说 Codex 装上它之后，产品经理、架构师、开发、测试的活它都替你排好了。卖点不是又一组 skill，是一套敏捷开发的角色分工，专治一个老毛病：需求没想清楚就开干。

良竹那条讲的是同一件事的另一面。他的说法是，只会调 API 的初级工程师在贬值，值钱的是 harness engineering，也就是模型外面那层壳。理由很实在：底模到处都是，但进了生产，模型胡说、进死循环、工具调用失败，全靠这层兜着。

"只会调 API 的会被淘汰"这话说得狠了点，喊了两年也没真淘汰谁。但方向我认。今年真正的差距不在你用什么模型，在于你有没有把它放进一个会自我纠正的结构里。同一个 Codex，有人一天烧掉几百万 token 换一堆 bug，有人能让它自己查资料、写代码、跑测试、顺手再指挥几个 agent。差的不是模型。

机场重开了，威胁也还在

沙特重开了利雅得机场。同一批报道里写着，胡塞武装这个月对这座机场发动过数次袭击，而且还在威胁后面继续。重开和威胁同时成立，这大概就是现在的中东日常。

以色列周二投票，选下一任总理。这条已经连着六天挂在榜上了，从前几天哈马斯袭击三周年的追责讨论一路排到今天。

还夹着一条讣告。圣经学者 Uriel Simon 去世，97 岁。讣闻里的说法是"著名的宗教鸽派"，他把圣经故事当文学文本读，也从里面替以色列找过道德上的指引。这条和上面两条放在同一个列表里，读起来不是滋味。一个人一辈子在经文里找和平的理由，而这一页的另外两条是机场、袭击和选举。

另一件更值得记：国际举重联合会决定把世界级赛事放到俄罗斯办，成了俄乌开战以来第一个这么做的奥运单项联合会。一场比赛本身没什么，但这个"第一个"的分量比奖牌重。制裁的墙开始出现第一道缝的时候，通常都是从体育这种"不那么重要"的地方开始的。

Starlink 那条也挺拧巴。Musk 说 SpaceX 限制了乌克兰的连接，理由是对方把网络用于军事，违反服务条款。现在服务已经恢复。战争里的商业条款，读起来总是别扭：一家公司按合同办事，而合同条款能决定前线的通信。

今天最轻松的一条

BBC 中文有篇讲观鸟的：看鸟怎么重塑大脑，怎么延缓认知衰退。今天所有新闻里，这条最没有争议，也最不像新闻。我把它留到最后，是因为前面那些看完之后确实需要点什么。

创业那边有两条我挺喜欢。独立开发者 William 宣布进入"威慑纪元"：只发 demo，死活不发游戏。demo 画风奇葩、系统复杂、叙事重度到能连载，让抄袭的人算不清账，也不知道那到底是真货还是烟雾弹。这是自嘲，也是小开发者真实的处境。

还有一条讲深圳。作者说时间线上突然多了很多外国朋友来深圳旅行的内容，然后自然地把中国和美国放在一起比。他顺手回忆 2024 年底刚创业时，The Information 的记者问他：介不介意在后面的披露里写明你们是中国团队。他说他聊了很久这个问题。

这个问题本身比答案有意思。三年前它还是个需要斟酌的句子，现在问的人少了，答的人也淡了。
