AI 与大模型：一边发布，一边打价格战

Claude Sonnet 5.5 在注册表里被提前发现

有开发者从 Droid 0.228.0 的模型注册表里翻出了 claude-sonnet-5-5 这个标签，位置排在现有模型后面。官方还没说话，社区已经把"即将发布"当成既定事实。同一时间，爱范儿的报道口径是 Claude 5.5 已发布、性能直逼 Fable、还要继续卷价格。

GPT-6 的三个名字：Sol、Astra、5.6 Sol

社区讨论里同时出现了 GPT-6 Sol、GPT-6 Astra 和 GPT-5.6 Sol 三个叫法，看起来是不同渠道对同一代模型的命名混乱。有人实测 GPT-5.6 Sol 在 Chat 模式下"温度"更接近 GPT-4o，人格感更强。另一条值得记的：OpenAI 把 GPT-6 新模型定到了"白菜价"，正面冲进 DeepSeek 长期守着的价格区间。DeepSeek 这边也没停，发了 Agent 训练沙箱 DSec 的论文。

Codex 和 Claude 的额度之争

有账号指出 Claude 的使用限额其实没涨，只是体验上感觉变宽松了；按原始配额算，Codex 给的仍然更多。这类争论没有官方数据支撑，只能算是开发者之间的体感对比。

两个模型在一个工作区里共事

有人把 Codex（GPT-6 Sol）和 Claude（Opus 5.5）放进同一个工作区，本来担心它俩打架，结果 Codex 发现彼此都在同一个 tmux 会话里，直接用 tmux capture-pane 看 Claude 在干什么，再用 tmux send-keys 给它发消息。另一个更工程化的用法是分工：GPT-6 Astra 负责后端、数据库和架构，Claude Opus 5.5 接手前端，顺便把 Astra 留下的过度设计、过度抽象和过度防护删掉。

这种"混编"到底算先进还是算补丁，暂时没有定论。支持者的理由是不同模型各有强项；怀疑者的理由是，真正的解法应该是让单个模型少犯过度设计的错。

开发者工具侧的变化

  • VS Code 装上 Cline 插件后，可以免费调用 Gemini 3.8 Flash、DeepSeek V4.1 Flash、MiMo-V2.6-Flash、Muse Spark 1.3 等模型。
  • qwen-code 把"能自己拆任务、自己记事"的编程助手塞进了终端，仓库一年前建的，已有 2.8 万 star、一千四百多个 issue 未关。
  • 乔木的 AI RSS 插件加了新配色，还有两款深色风格，晚上读着不刺眼；配 Qiaomu Agent 插件可以做更多事，比如抓出文章里的歌名丢进 Spotify，或者调 Codex 的 imagegen 把文章转成信息图。

把 AI 当实习生用，是浪费

一条传播很广的吐槽说，90% 的人一开口就把顶级模型当实习生使唤："帮我写个程序""修一下这个 bug""做个网站"。发帖人的结论是，问题不在模型，而在提问方式，得把它当正经搭档而不是许愿池。

研究场景：15 分钟排序千亿级数据点

一个斯坦福的研究组把 JEV 和 Claude Code 拼起来，每 15 分钟处理一千多亿个数据点。这类案例的说服力在于它有具体的量和时间窗口，而不只是"AI 提效"的口号。

开源侧：两个很实用的项目

  • easyquotation：5.4K star、MIT 协议，接新浪、腾讯、集思录三个源，单只、多只、全市场快照都能取，全市场五档盘口 200 多毫秒到手。作者的话挺有意思——现在的新库都在卷 MCP 和 AI 接入，但很多人忘了最基本的诉求其实是"快"。
  • easy-stock：把行情分析、市场情绪、财经资讯、AI 智能投研打包成一个桌面应用，主打散户也能有一套自己的投研工具。

这两个项目都出自同一天的推送，一个是底层取数，一个是上层应用，刚好构成一条链。

开发工具：三个不太起眼但省事的项目

  • Naive-N0.5-Flash：Naive AI 的首个模型，309B MoE、激活 15.5B、原生 1M 上下文、最高 2000 tok/s，官方称在开源模型里排前列，coding 和 AI R&D 是强项。发布者强调这是"用 AI 造前沿 AI"的产物。
  • Windows Developer Config：微软开源的一套配置脚本，重装或换电脑后，Git、Python、VS Code、WSL 这些环境一次跑完，不用一个个装回来。
  • NewsNow：把微博、知乎、抖音、GitHub、Hacker News、V2EX、华尔街见闻的热榜聚合进一个页面，按国内、国际、科技、财经分类。对不想挨个刷 App 的人很实用。
  • geo-score：输入网址，约 20 秒出一个 100 分制的评分，21 项检查，专门衡量网站能不能被 ChatGPT、Perplexity 这类 AI 搜索引用。它针对的是一个新问题：Google 排名很好，但 AI 回答里从来不提你，而且很难查原因。
  • Interfaze lev：被称为"开源版 Jev"，基于 Qwen-3.5 4B，针对同一段文本能同时回答判断题、单选题和打分题，不逐字生成，直接读模型内部概率，多题共享一次计算，耗时接近单次提问。

AI Agent：从选模型转向做支架

一条讨论问得挺尖锐：为什么顶尖的 Agent 团队都在谈 Harness Engineering（运行时支架工程）？发帖人的观察是，很多人以为做 Agent 就是挑一个高智力基座模型、配一组提示词和几个 API，但在长链路场景里（自动化代码重构、多步数据分析），模型能力只是及格线，真正决定成败的是运行时那一层。

配套的还有斯坦福 CS329A《Self-Improving AI Agents》，9 讲视频都已放出，第 1 讲 52 万观看，第 9 讲 1.5 万。
