每日资讯早报 2026-10-31

2026-10-31 · 每日资讯早报 · 288 条信息

今天能让人停下来的只有两件事。币安丢了 63 亿美元，史上最大的加密盗窃。以及一批开源项目把“给 AI agent 一整套专业工作台”做成了能直接下载的东西。一个是把信任交出去之后的代价，一个是把能力拿回自己手里的尝试。同一天发生，挺有意思。

一、63 亿美元，和一个说不清的“赔付”

币安确认被黑客盗走约 63 亿美元。NYT 早先的报道写的是“超过 60 亿”，后续数字统一到 63 亿；BBC 说这是有史以来最大的网络盗窃案。BBC 中文提到朝鲜黑客组织被指涉案。币安称攻击手法复杂，会赔付受损客户。

四家媒体的框架不太一样，对照着看更有意思。NYT 有一篇的标题直接写着“63 亿美元的失窃只是个开始”（原文说的是这次盗窃开启了一个风险更高的新阶段），落点在攻击者越来越多地使用 AI 和其他自动化手段。BBC 走的是溯源路线，盯着“谁干的”。NYT 另一篇回答读者最直接的问题：普通用户有什么保护？答案是公司说会赔。BBC 中文补了一个容易被忽略的背景：币安在 2026 年年中占整个加密市场交易量的 35% 到 36%。这个体量意味着一次失守不只是这家公司的事。

链条不难推：钱集中在交易所，一次攻破的收益高到离谱，所以总会有人动手。赔付能救回用户的钱，剩下的两样救不回来，一个是信任，一个是两年后监管者的耐心。

我的看法：63 亿美元这个数字已经大到失去实感了。对普通人来说，真正的问题是“我的币在不在赔付名单上”，以及“下次还赔不赔得起”。托管型交易所的核心卖点一直是“你不用管私钥”，这句话现在得加个括号。

同期还有一条线。BBC 报道美国科技股因 AI 成本担忧大跌，Intel 继续下跌，纳斯达克开盘创数月新低。加密社群这边，日本漫画家井上純一在推上劝人别急着抄底，说泡沫破裂的过程向来很长。科技股和币圈在同一个星期一起回调，我不觉得全是巧合，但也不想硬找一个统一解释。钱变贵的时候，估值高的东西总是先被重新定价。

二、开源这边，把整个组织塞进 agent

Scenario 开源了 3D OS，一整套 3D 工作室，给 coding agent 配了 6 个“部门”和 80 个 skills。另一个项目 Claude Code Game Studios 走得更远，直接把 Claude Code 改造成一个游戏开发环境。还有 pixelfx，232 个像素动画特效，没有一个图片文件，每个效果就是一小段代码，支持实时预览、换色、镜像，能一键导出 Sprite Sheet，自带 Claude Code 的 skill。

看下来，这三个项目给 agent 的都不是工具，是编制。部门和 skills 的隐喻很直白。模型未必需要更聪明，它更需要知道此刻该叫谁上场。

模型侧，Unsloth 放出 DeepSeek-V4.1-Flash-1017 的 GGUF，Dynamic V3.1 量化，发布方称 64GB 内存就能跑，多项基准表现好于预期，还把 Engram 放到 SSD 上按需读取。这类消息我一般打七折看，“多项基准全面碾压”是推广语。但 64GB 这个门槛确实往下砸了一截，本地跑大模型从“要不要买服务器”变成了“看看手头这台机器”。

学习资源也跟上了。cs329z-chinese 把 Stanford CS329Z《Engineering AI Agents》整理成中文，19 讲加 4 个动手练习，从大模型讲起。英文啃不动的人这次没借口了。

视频生成那边，MiniMax-H3 的开源工作流在预热。有人用 96GB 显存的卡跑出了接近工业级的流程：双通道 463MB/s 预热、双角色原生声纹锁定、首尾潜变量夹具、3 分钟的单段局部重修。另一条消息说 11 月 3 日会发完整工作流，2K 画质，7 秒视频生成 3 分 25 秒，15 秒要 6 分多，支持 2K 续拍，配了文戏质感、武打增强、运镜增强、人脸精修几个 LoRA。硬件门槛还是高，但工作流一旦开源，门槛降得比模型快得多。

三、平台在收紧

Claude 把套餐改名了。Max 5x 变成 Max，还是 100 美元一个月；Max 20x 变成 Ultra，还是 200 美元。价格没动，订阅者不受影响。改名本身没什么可说的，但它说明这些公司开始认真做产品分层了。

另一头不太好看。一位 Claude for Startups 成员在 Reddit 发长文，说自己靠 Claude Code 做桌游数字化生意，Anthropic 突然加了一条游戏相关的限制，直接把开发卡死。他是被扶持计划选中的创业公司，规则改起来照样不打招呼。

还有一条爆料，来自爱范儿：Fable 5.5 正在被测试，有用户在使用 Opus 5.5 时发现，Claude 每次回答之后还会执行一条用户看不到的指令。这条没有独立验证，只能当爆料看。但和上一条放在一起，问题就很具体了：你付钱买的是一个会执行你看不见的东西的服务，条款和实现都不在你手里。

这也是我为什么对“开源一整套工作台”那类项目更有好感。不是因为它更好用，是因为出了问题你能读代码。
