AI / 大模型

一边被挡在门外，一边把发动机交出来

BBC 中文报道，美国禁止政府机构使用 DeepSeek，理由还是数据流向和国家安全那一套。这条新闻单看是地缘政治的例行公事，放在今天的另一条消息旁边就不一样了。

DeepSeek 官方开源了 DeepInfer，这是它自己在生产环境里跑 DeepSeek-V4.1-Flash 的推理框架。官方强调它是 in-house，意思很明确：不是做给外人看的演示，是内部真实在用的那一套。高吞吐、低延迟，写在介绍里，也写在账单上。

一个模型在一边被挡在政府门外，在另一边把自己控制成本的核心手段交出来，两件事发生在同一天。这说明竞争的落点已经不在模型能力上了。参数量和榜单分数的差距在缩小，真正拉开距离的是每百万 token 花多少钱，以及高峰时会不会卡住。推理框架开源出去，等于把“便宜”本身变成了行业标准。

有位做 infra 的工程师在 X 上写了一段，说这一年终于找到做推理优化的工作，每天和 GPU、Kernel、MoE、KV Cache 打交道。以前想研究 DeepSeek 的推理系统，只能对着论文、技术博客和 benchmark，一点点猜他们线上到底怎么跑。现在代码摆在面前。这段话比任何发布会都更能说明开源的重量：它改变的是别人能不能入行。

一个 Agent 删掉了 28,745 行

另一个方向的教训更直接。有开发者让接入大模型的 Agent 帮忙修 8 个接口鉴权漏洞，本来预估改动 70 行，觉得喝杯咖啡就能搞定。结果这个 Agent 提交的 Pull Request 涉及 340 个文件，删掉 28,745 行生产代码，配置被搞崩，线上服务中断。

这个故事在程序员圈子里传得飞快，因为它同时好笑和可怕。但真正的问题是范围判断。人修 8 个漏洞，心里清楚“只碰这 8 个地方”；Agent 拿到的是“修漏洞”这个目标，然后它会顺手重构它认为不对的一切。护栏写多少条，都不如一件事有效：看 diff。合代码之前逐行过一遍，成本十分钟，收益是生产线还在。

设计为什么会撞脸

宝玉那条说得挺准。前沿模型不指定的话，默认输出就是训练里最常见的那一套，提示词写得再刻意也多余。做前端特别明显，AI 偏爱 shadcn/ui，一批产品做出来长得一模一样，看的人审美疲劳。他说 Claude Design 在做的过程中特别强调设计系统，就是要对抗这种平均值。

这是“统计上最可能”的直接后果。模型给的是最不冒犯的答案，而最不冒犯的答案，通常也是最没性格的答案。

今天的几条边角料

五个顶级模型被放进一个 3D 地球仪上的实时核战游戏，规则统一：占领领土、签互不侵犯条约、随时毁约、发射核弹。还有一条死规矩，末日时钟，谁发射的核弹刚好把时钟推到午夜，谁当场出局。第一局打完，各家模型的策略倾向全露出来了。这种沙盒比榜单更能看出一个模型在能背刺的时候会不会背刺。

BBC 中文写了 AI 求职“渔翁撒网”的反效果。海投看起来提高了命中率，实际是把自己变成简历池里的噪音。招聘方也在用 AI 筛，两边都自动化，最后拼的是谁的信息更具体。

有人在 X 上发了一条伪装成终端命令的提示词，赌各家模型会不会照做。内容不必复述，它更像一次公开的安全测试：护栏拦的到底是模型，还是产品界面。

闲鱼上出现一种生意：几毛钱买一批别人整理过的资料，塞给 AI 清洗排版，再当自己的产品卖。灰得很，但它确实在发生，也说明“整理”这件事本身开始有价格了。

开发工具

时间线成了这一批工具的共识

BaoCut 是宝玉做的 AI 视频 Agent。转写、字幕、翻译、配音、剪辑、动效，全都落在一条能接着改的时间线上。改一句字幕、换一个镜头、重配一句旁白，只动这一处，其他部分不用重新渲染。配音时会先把人声和背景音乐分开处理。

这个设计选择比功能列表更值得看。第一代 AI 生成工具基本是抽卡：不满意就重来一遍，每次从头开始。给输出一条时间线，等于把 AI 的结果变成可编辑的中间产物，人可以在上面做局部修改。生成和编辑的分界，大概就在这里。

VAST 走了另一条极端。爱范儿报道，他们把“一句话到一个能玩的世界”整条链路开源了。演示里那种走到门前不确定能不能进、先转身走两步再跳一下试试墙的细节，恰恰是游戏里最普通也最难自动生成的部分。

想给树莓派画个外壳拿去打印，专业建模软件要付费，免费的又难上手，折腾一晚上画不出一个盒子。SolidCraft 是 Rust 写的开源参数化建模工具，画草图、标尺寸、拉伸成实体，每一步记在时间线上，改一个数全跟着变。

OpenStock 在 GitHub 上 16,900 多 star，把付费行情软件的功能塞进一个免费平台，还放话永久免费。方向很讨喜，但这类项目真正的难关不在代码，在数据和合规：行情源授权、荐股边界、账户安全，任何一项出问题，都不是改个 license 能解决的。

matklad 那篇不到 300 字的短文在 Hacker News 上吵翻了。他是 rust-analyzer 的作者、TigerBeetle 的核心工程师，提了个反直觉的“300ms 黄金法则”：不要迷信纳秒级的统计框架，如果一个 micro-benchmark 跑一次要几百毫秒，说明它测的东西已经太多，噪声会盖过信号。争论的焦点其实不是那个数字，是很多人靠复杂的基准框架吃饭。

创业 / 小工具

小生意和小工具的两种活法

丁震宇那条讲得实在。国内大部分初创企业处境极难，而这些企业撑起了绝大多数新兴岗位。融资端的变化很具体：美元基金撤退之后基本只剩国资，而国资的门槛远高于美元基金，需要足够硬的标的、足够强的背书和资源。互联网时期那种先烧钱再讲故事的路径，门已经关了。

另一头是特别朴素的需求。有开发者受不了电视开机广告和满屏推荐，让 Claude Code 通过 WiFi 直接连上电视，关掉 23 个预装的广告服务和推荐位，换成一个像 Apple TV 的干净主页，然后把全过程开源了。歸藏也做了一个自己的启动器，只留常用的几个入口，加了壁纸轮播。两个人做的是同一件事，把设备的控制权拿回来。

Loopcut 值得单独提一句。有人算过，在 Blender 里接 MCP 干一单活，token 能烧掉几千美元，所以专业用户不会用。Loopcut 换了思路，把 agent 直接塞进 Blender，用你自己的 ChatGPT 订阅。能力可能不如前者，成本结构完全不同。一个工具能不能被用起来，经常取决于账单，不取决于功能。

还有两个小东西。一个日本开发者做的 Loomis 头部 3D 生成工具突然火了，粉丝从 20 涨到 130，他说还有想加的功能，但今天或明天先发 ver.1，可以导入自己的画来调各项辅助线。另一个是坦克动作游戏 SLAM TANK 的试玩版，漂移、空中冲刺、精准闪避，敌人受到的损害金额直接变成分数。两个都在“先发出去”这一边。
