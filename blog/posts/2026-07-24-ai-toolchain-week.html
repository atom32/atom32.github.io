API 路由从手动换 Key 到自动切换

OmniRoute 是一个开源自托管的本地 API 网关，统一管理 278+ 供应商、500+ 模型。最实用的功能是：当前通道限流或报 429 时，按策略自动切换到备用通道。经常跑长任务的朋友都知道，跑到一半额度耗尽、接口报错，然后手动换 Key 重启——这体验太痛了。OmniRoute 正好解决这个。开源、自托管，兼容 Cursor、Cline、Claude Code 等工具。

MCP 把数据层直接嵌进工具链

Topview 出了一个 MCP server，把 Amazon、TikTok Shop、YouTube、Shopee 的市场数据直接内置。传统做法：凭感觉选题 → AI 加速执行一个可能错误的方向。Topview MCP 的逻辑是反过来——先告诉你什么值得做（数据驱动），再帮你把策略、分镜、素材一起跑通。而且 Seedance 2.0、Kling 3.0、Veo 3.1 都是内置的，不需要自己拼工具链。这才叫 full-stack——不是功能堆砌，而是链路完整。

看到「小小东」在积累提示词库，目标是 2 万组。这是一个很有意思的信号——当大家还在讨论单个提示词怎么写好的时候，已经有人在用规模化思维做提示词资产库了。提示词不再是随手写的文本，而是可复用、可分类、可迭代的工程资产。这跟软件工程里从写脚本到写库的进化路径一模一样。
