一、模型三连发：GPT 6.1 Sol、Gemini 4、Opus 5.5

昨天 OpenAI 放出 GPT 6.1 Sol，官方说法是性能贴近 Astra，但速度和成本更适合日常高频使用。社区很快给出一个挺实用的分工：GPT 6.1 Sol 跑日常的写代码、做 Agent、设计 Skill、开发任务和方案讨论，Astra 挂成「架构师 Agent」按需调用，而不是每一轮都上。（Codex 使用技巧，@thedelost）

有意思的是速度反倒成了疑点。有用户实测 GPT 6.1 Sol 只有 20 tok/s，比 Astra 的 30 tok/s 和 5.6-sol 的 50 tok/s 都慢，于是怀疑它是不是一个官方没说的小模型。（@mylifcc）

谷歌这边发布了 Gemini 4，内部代号 Argon，定位是长周期复杂工作流：单次输出上限从 64K 直接拉到 100 万 token，首发定价输入每百万 token 2 美元、输出 10 美元，缓存输入打折到 95%。社区对该系列评分给出的判断是「大幅领先」。（@Gorden_Sun / 官方发布）

Anthropic 的 Opus 5.5 没开发布会，但产出很密。有人整理了它一周内产出的 10 个 GitHub 仓库，从动态图形到完整游戏都有。更值得记的是用法：它不能直接生成视频，但能写 Canvas、WebGL、Three.js 和 Remotion 的代码，把每一帧画出来再拼成 MP4。试过的人说，这条路可能比直接出视频更好用。（@social / @gkxspace）

二、Agent 正在长出「组织」

Pi 上最近流行一个插件 pi-subagents：可以在 Pi 里拉起多个独立 Subagent，不是另开一堆 CLI 子进程，而是直接跑在 Pi 自己的 runtime 里。装上之后，「Multi-Agent」从一个概念变成了一个开关。（jopqior/pi-subagents）

Prime Agent 走的是另一条路。这个仓库今年 5 月才建，现在已有 2.1 万 star、2300 多个 fork，MIT 开源。它的卖点是会自己开分身、自己攒技能，用得越久越贴合使用者的习惯。瞄准的痛点很具体：Agent 干长任务时上下文一满就丢东西，上周纠正过的毛病下周照犯。（@Ryrenz）

OpenAI 今天发布的 dots 是第三种形态：24 小时在线的个人 Agent，自带云电脑和浏览器。巧的是 GitHub 上个月就有人开源了思路相近的 Rakazo，每个 bot 有自己的对话、记忆和定时任务，干活时也能调一台电脑用。（@GitHub_D）

登录方式也在松动。今天凌晨 OpenAI 升级了 Sign in with ChatGPT，现在用 ChatGPT 账号登录 Devin、Notion 等 16 个第三方产品，可以直接消耗套餐额度，不用单独买 API。（@yupi996）另一边，因为调整了 200 美元 Pro 会员的额度，OpenAI 给受影响的用户补了 62,500 点积分，长期有效、年底过期。有用户吐槽：这些补偿如果在宣传时一次说完，昨天的抵触情绪大概不会这么大。（@op741）

三、工具圈的新东西

Railway 推出免注册 VM：终端里敲一条 ssh 就能连，约 1.4 秒起来，2 vCPU / 2GB，预装 Node、Python、gh，以及 Claude Code、Codex、Cursor CLI、Grok 这些 coding agent。（@dingyi）

disktree 开源磁盘占用可视化工具，把全盘文件铺成一屏彩色方块，谁占空间一眼可见。作者称直读磁盘底层，近 50 万文件 3.1 秒扫完。

Gnos 开源 AI 教学工具，装进 Claude Code 或 Codex 之后，它更像一个会排课的老师：先说明想学什么、学到多深、每周有多少时间，它再参考大学课程大纲和教材来安排进度。（@GitHub_D）

DeepSeek Harness 生态里出现了第一款第三方插件 Qiaomu AI RSS，聚合成海外 AI 资讯、播客和新工具介绍，并提供中英双语改写。（@vista8）

yomiyasu 一个把「AI 味」日文改写成自然日语的技能。作者说思路和常见的「禁用某些词」不同，重点是还原句法结构（谁对谁做了什么）和把比喻动词具体化。Claude Code、Codex 都能直接用。

ah-skill 抖音生态工具箱更新，主打批量提取逐字稿。作者说以前要花 5000 块找人做，现在 Codex 半小时能跑 150+ 个视频，消耗约等于 5x 账号周限额的 0.5%。（@Astronaut_1216）

提示词这边两篇挺互补：一篇给出 GPT image 2.5 的通用模板「主体 × 风格 × 构图 × 媒介」，另一篇（@huoshan007）的观点更直接——别再说「帮我做个图」「设计一张传单」「做张海报」，这三句话一出口，就是把顶级设计师当打印店前台使唤，出来的自然是千篇一律那种。

关于 AI 写前端的审美，@realchendahuang 的吐槽挺准：基本逃不过「万物皆卡片，卡片里套卡片」，再加上蓝紫渐变和零位移光晕。想往里加「极简、高级、现代、科技感」也没用，因为训练集里塞满了全世界最平庸的开源模板，概率分布算出来的最优解就是它们。
