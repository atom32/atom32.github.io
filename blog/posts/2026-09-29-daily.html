AI 与大模型：三场发布挤在一起

Cue 是 Manus 2.0 的那把新刀

Manus 推出 2.0 版本，同时上线个人 Agent 产品 Cue。目前限时免费，原本 20 美元／月的套餐可以直接试，流传的邀请码是 MEETCUE。定位上说得很直白：对标 Grok bot 和 Meta 的 muse，一句流传的总结是"Cue 负责生活"。只对海外开放。

最抓眼球的不是免费，是手机号。Cue 允许给每个 Agent 配一个号码，一个美国号码 0.99 美元，好几个账号直接把它读成"方便注册 Claude Code 过验证"。有人手更快，已经在推中国移动 CMLink 的英国卡：1 英镑、免实名、有流量、支持通话短信上网，而且是实体卡能直邮国内，绕开了 eSIM 设备和转运的麻烦。

至于动机，评论区的猜测是 Cue 本来打算和 Meta 一起发，因收购问题被"截胡"了。这属于社区说法，没有任何官方确认，听听就好。

也有更冷静的声音。一位长期用 Grok bot 的用户建议把它当总调度，底下挂 Codex、Claude Code、DeepSeek Harness、muse 各干各的活："只靠它自带额度是不够的。"这个思路跟今年反复出现的 harness engineering 讨论是同一件事——Agent 能不能干活，越来越取决于外层的调度和运行时，而不是底座模型的名次。

更实际的是钱。Codex 的 100／200 美元档位，续订页现在只写"比 Plus 更多用量"，不再写固定倍数，5x 和 20x 消失了。如果真变成动态额度，Pro 值不值得买就得重新算。有人已经算了：即使只用 GPT-6 Sol 干活、用 GPT-6 Astra 规划，200 美元套餐的实际用量也就 Claude Pro 的一倍左右，再算上 Astra 和 Sol 来回返工的开销，他在考虑退订。

开发工具：几个省事的项目

  • anydoc：Firecrawl 团队用 Rust 写的格式转换器，14 种办公格式统一转 Markdown，转换速度中位数不到 5 毫秒，star 已经过 1.2 万。痛点抓得很准——Word、PPT、Excel 各转各的，质量飘忽，光这一步就能耗掉半天。
  • Dcomputer：Cloudflare 开源。把虚拟文件系统和执行环境凑到一起，让 Agent 能真的读写文件、执行命令，而不只是聊天。有评论说，Agent 缺的可能不是"容器"，是一台"电脑"。
  • Cloudflare Pages + Workers：一条给独立开发者的建议，做个人小工具或出海小产品别去买云服务器、配环境、折腾 Nginx。静态前端扔 Pages，连 GitHub 自动构建、全球 CDN；后端接口丢 Workers，毫秒级冷启动。
  • OpenSpot Music：开源音乐播放器，免费无广告、不用登录，Android、iOS、macOS、Windows、Linux 都覆盖，主打无损音质和离线。
  • 科技上网工具索引站：把 Clash、Mihomo、sing-box、Xray、V2Ray 这些客户端分类整理到一个站点，光客户端就收录了 149 款。以前需要在 GitHub 里翻很久的东西，现在一页能看完。

这几个项目有个共同点：都不是新概念，只是把一件本来就烦的事做短了。这类工具的实际价值往往比发布会上的模型名次更高。
