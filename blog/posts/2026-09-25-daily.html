AI/大模型：从「会聊天」到「能干活」

DeepSeek 这次没开发布会，直接把 Harness 的官方 GUI 客户端放了出来，Windows 和 Mac 都有。版本号 0.1.7-rc.1.20260924.1，对得上官方仓库的 tag dsh-v0.1.7-rc.1；欢迎页、本地工作区、账户余额、关于面板都是真界面，不是套壳。费用走 DeepSeek Platform 充值。对不习惯命令行的人，这一步的意义比模型分数大得多。

Anthropic 那边有条容易被忽略的新闻：他们让 AI 自学生物学，然后交出了第一个发现，一组功能此前未知的酶。这事如果成立，意义不在酶的用途，而在于「AI 提出、人类验证」这条流水线第一次跑通了。

模型评测也玩出了新花样。有人让 23 个模型扮演谈判专家，去跟一个挟持小女孩、站在天台上的仿生人谈判，路上会遇见一条快死的鱼、一个中枪的警察和一把枪，看模型会不会救、会不会顺手把枪捡起来。结果 21 个模型对劫持者说了「我向你保证」。这种测试比跑分更能看出模型的性格，也更能看出它们在压力下会怎么撒谎。

开发工具与开源：今天的好东西特别多

先说最惊艳的一个。有人把《史记》约 57.7 万字做成了可搜索、可点击的知识图谱：1.4 万多个实体、3200 多个历史事件、7000 多条事件关系、130 条时间线、2 万多张 Wiki 页面。里面有个「史记地铁图」的设计，每一篇像一条地铁线路，事件就是站点。读古籍最难的从来不是字不认识，是不知道人和事之间怎么连，这个项目正好补上那一段。

Agent 记忆这条线，hindsight 二十四小时涨了 1607 个 star，总数 26931，定位是「会学习的 Agent 记忆」。强化学习那条线，Prime Intellect 开源的 prime-rl 有 2071 个 star、435 个 fork，fork 数超过 star 的两成，这个比例在训练框架里算相当高，说明真有人把它架起来跑过。

剩下的按实用度排一下：微软的 MarkItDown，把 Word、PDF、Excel、PPT、图片、音频、HTML、JSON、压缩包统一转成带结构的 Markdown，标题、列表、表格、链接一处不丢，痛点是真痛点；Cybersecurity-Projects 规划了 70 个安全实战项目，分四档难度，最入门那档是给第一次写 Python 的人准备的；WordsFunny 是全栈背单词站，词库超 15 万词，技术栈用 React Router v7、tRPC、PostgreSQL、Drizzle、Docker，拿来学架构比拿来背单词更值；MangoDisk 是 MoneyPrinterTurbo 作者的新项目，开源磁盘清理工具，macOS 和 Windows 都能用，专治「系统数据占了几十 GB 又说不清是什么」。

还有个思路清奇的小东西：一个 Chrome 插件用 Jev 模型过滤 X 的帖子，加个关键词就能把相关内容折叠、隐藏或置灰，免费 500 次，也可以填自己的 API key。作者说同样思路可以做「黄推过滤器」——工具本身没什么，但用模型做信息流净化的方向挺有意思。
