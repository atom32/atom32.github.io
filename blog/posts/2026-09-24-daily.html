AI 与大模型

Anthropic 在 9 月 17 日公布了一组结果：在两名技术人员监督下，Claude 花了不到四周，协助优化了 30 多个开源生物学模型，包括 AlphaFold3 和 Boltz-2，优化代码已开源。需要留意的是"监督"两个字，模型在这里干的是跑实验、调参、看结果这类重复劳动，判断和方向还是人给的。

同一天被反复提到的还有 PhAILabs 的 ScienceBuddy，定位是围绕科研工作流设计的 AI Agent，免费工作空间，可以在里面用 GPT-6。朋友圈里有人安利，说试过不少科研 Agent，能把完整流程跑下来的并不多。同一批讨论里也出现了 Opus 5.5 的存在，官方提示词指南调整了 effort 的默认值，从原来的高档位降到了 medium，官方称 medium 的表现达到或超过 Opus 5 的 high。指南里另外几条也挺实在：思考模式关不掉，别写"think carefully"，长任务跑完先问它"还缺什么才能继续"，不要急着接手。中文区有人攒了 24 条使用 tips，也有人拿它直出创意编程和动态设计，评价相当高。

工程侧的新动向是把散落的经验固化成 Skill。有人做了安卓逆向的 Skill，装进 Codex、Cursor 或 Claude Code 后，遇到 APK、前端代码、固件这类目标会自动判断分析路线、选工具、排下一步。安卓逆向本来链条很长：解包、反编译、改 smali、重签重打包、Frida Hook，再到 so/native 层分析，现在这一整套被打包成了可以让 Agent 编排的东西。安全圈几年踩坑攒下来的手感，正被写成可复用的文件。

生图这边，Unsloth 把 Qwen-Image-2.1 的本地部署门槛压得很低，FP8 offload 之后 6GB 显存能出图，Mac 统一内存 16G 也能跑。但有人提醒，官方的提示词改写器是另一道锁：你的一句话会先被扩写成详细英文提示词再交给模型，而这个改写环节自己也会拒绝请求，原版测试里 100 条拒了 98 条。生图模型和文本编码器处理得再干净，卡在这一环照样白搭。

Agent 基础设施方面，DeepSeek 的沙箱平台 DSec 被当作《深入理解 AI Infra》的典型案例来讲。工具层面，Wake 是个用 Rust 和 GPUI 写的原生桌面应用，专门收拾多个 Agent 会话散落在十几个目录里的乱局；ai-memory 则想让 Claude Code、Codex、Cursor 共用同一份记忆，作者是 Fabio Akita，仓库五月底建，四个月涨到 8000 stars，最近一周发了四个版本。wx-cli 走得更近，直接读 Mac 本地的微信数据，让 Agent 能搜聊天记录、读联系人和群聊、提取图片语音，甚至实时监听新消息，数据默认留本机，还自带 Agent Skill。另外有篇文章叫《你对 AGENTS.md 的理解几乎为零》，引了乔布斯那句关于"把流程当成内容本身"的话，批评意味挺明显。

开发工具

Jev 发布刚满 8 天，开源替代已经冒出一堆，连诺基亚都来凑热闹。有人在 MacBook 上让官方 Jev 和三个开源方案同跑 20 张中文工单：Laya 25 毫秒，比官方快约 50 倍；djev 509 毫秒；官方 Jev 1.3 秒；AnyJev 接近 4 秒。配套的还有导航站，把 GitHub 上真正在调用 Jev 的开源项目收全了，788 个项目、182 个当场可跑、765 条源码调用证据，分类每天自动更新。它的卖点是不看 README 里怎么吹，直接看源码里怎么调。

语音合成也有了新选择。Kyutai 开源了 Pocket TTS，约 1 亿参数，主打在 CPU 上本地跑。官方在 MacBook CPU 上测出的速度最高接近 6 倍实时，首块音频约 200 毫秒生成，只需要 2 个 CPU 核心。以前做 TTS 要么上 GPU 要么接付费 API，这条路子算是被打开了一点。

视频生产线上，有人用 Opus 5.5 把最后一公里打通了：口播交给数字人生成，剪辑派 Agent 套用训练好的"网感"动效做 A/B-roll 编排，最后自动出片并推成剪映工程文件。另一头，GitHub 上 2600+ stars 的「狗头军师」把恋爱咨询做成了 Codex Skill，丢进聊天截图和记录，它来分析态度、判断关系、拟话术。elizaOS 则把 Agent 从框架做成了整套可装机系统，聊天、语音、记忆、自动操作电脑都在里面，1.9 万 stars，五千七百多个 fork，一千四百多个 issue 开着。fork 数接近 star 数的三成，说明确实有人在拿它改东西。
