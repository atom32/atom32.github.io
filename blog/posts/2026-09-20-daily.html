一、Jev：今天全网只有这一个词

如果你今天只刷到一条科技新闻，大概率是它。Jev 在中文和英文圈同时起量，语气基本分成三种：一种说它是 agent 栈里一直缺的那一层，顺手给出流程解释，状态到决策、决策到动作、动作到验证、再回到下一个状态；一种直接甩数字，说速度快 20 到 200 倍，成本降 40 到 400 倍，另一处口径更进一步，写成最高快 193 倍、便宜 444 倍；还有一种最容易被转发，就是拿它跟 Claude Code 和 Codex 划清界限。

划界限的那句话来自 Jev 创始人 Diogo Almeida，OpenAI 前员工。大意是下一个时代不属于 Claude Code 或 Codex，因为那两个还停留在辅助阶段，人始终在回路里。这句话之所以传得开，是因为它把一个技术话题转成了叙事话题：不是又快了多少，而是到底谁来干活。

落地有人把能找到的 Jev 项目翻了一遍，列出来的第一个例子是 jev-ultrafast，一个 Browser Use 的高速 agent，Jev 负责每一步判断，整个 Google Flights 搜索走完大约七秒多。也有博主把某篇长文里的八个案例拎出来，说这些至少带着源码仓库，还顺手扒了官方文档里几个容易被踩的坑。

这波传播里，数字被引用的次数远多于复现的人。速度快 20 倍和快 200 倍都能在今天的转发里找到，两者差了十倍，却几乎没人追问测试条件。这类参数在看懂之前，先当宣传口径看更稳妥。
