AI 与大模型

腾讯开源 BrowserSkill：让 Agent 用你正在用的浏览器

做法是把「CLI + 浏览器扩展」拼在一起，任何能执行 shell 命令的 Agent 都能操作你真实、已登录的浏览器窗口，干完活再把标签页还给你，不打断你手上的事。MIT 协议，全本地运行。

对比 Playwright 那一类的老路，差别挺实际：以前要给 AI 单独开一个干净的空白浏览器，登录态、Cookie、插件全得重建一遍。推上的评价是"把浏览器 Agent 最恶心的一道坎给做穿了"，对天天泡在 Cursor、Claude Code 里的人值得先翻一遍。

Codex 额度不够用，有人把 ChatGPT Web 接成了原生模型

Codex 强但用量卡得难受，ChatGPT 额度多却只能在网页里手动复制上下文。这个开源项目的思路是：在 Codex 里直接选「ChatGPT Web」，任务上下文和文件都不动，只把背后的模型换掉。

Birdview：先画架构图，再让 Agent 改代码

痛点描述得很准：一个需求下去，Agent 一口气动十几个文件，改动一行行翻过去看不出牵连了哪几个模块，合并了才发现碰到别处。Birdview 的办法是动手前先给项目生成一张架构地图，标出这次准备碰哪些模块，每个模块有固定编号、归属文件和对应关系，Agent 在这张图看得见的情况下再改。

OpenAI Prism 里的 GPT-6 Astra

9 月 16 日有 reddit 用户报告，Codex 额度耗尽之后，登录 OpenAI 自家的 LaTeX 编辑器 Prism，居然能直接用上 GPT-6 Astra Extra High。这种没写进文档的入口通常活不长，看看就好。
