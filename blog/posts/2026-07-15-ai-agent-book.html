《深入理解 AI Agent》开源书发布

2026-07-15 · 来自 X 时间线 · #AI Agent

Bojie Li（李博杰）去年在图灵讲的《AI Agent 实战营》终于整理成书了，GitHub 开源免费下载。

《深入理解 AI Agent：设计原理与工程实践》
核心公式：Agent = LLM + 上下文 + 工具

为什么值得看

市面上讲 Agent 的资料大多要么太学术（论文级别），要么太营销（"10分钟搭一个 Agent"）。这本书是少有的从原理到工程实践都覆盖的。

十章内容概览

全书围绕核心公式展开，覆盖：Agent 设计原理、工具调用、上下文管理、多 Agent 协作、生产化部署等。

一点感想

从我的 X 时间线来看，最近三个月 Agent 相关的讨论密度明显在增加。从 AgentKey 接入中文互联网，到 Fusecode 的模型订阅方案，再到各种 RAG 课程——这个方向还在快速进化中。

这本书的发布刚好填补了一个空白：系统的工程实践指南。
