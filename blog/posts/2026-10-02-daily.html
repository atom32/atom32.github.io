一、Agent 慢慢长出一间「办公室」

@bkdgiffug 提了个叫 Munder Difflin 的东西，打开电脑，屏幕里直接是一间虚拟办公室。它把 Claude Code、Codex、Kimi、Qwen、Copilot 这些终端 AI 变成一个个独立 Agent，每个都有自己的终端、记忆和收件箱，你能看着它们各自干活、互相递活。听着有点像把早年的多窗口终端套了层情景剧的皮，但换个角度想，Agent 的形态确实在从「一个助手」往「一个小班组」挪。

@NFT_Chen 今天做了一份四款 AI Bot 的横评，拆的是 Grok Bot、Dots、Cue 和 Muse。他的判断是这几样东西的定位已经变了：不再是聊天机器人，而是往「有身份、有分工、能长期执行任务」的方向走。同一个方向，OpenAI 的 Dots 走得更远一点，@goan9 整理的教程把它拆成了 agents、models、tools、memory 几层，还说这是全网独一份。有意思的是 Codex 用户也有自己的玩法：@ArchiveExplo 的建议是让 dot 来当 manager，别让它自己写代码。一句话，身份比能力先立住。

二、限速疑云：同一只模型，快慢差三倍

今天的争议集中在一件事上。Codex 订阅里的 GPT-6.1-Sol 处理速度明显变慢，官方出来解释，说慢的不是模型本身，是 6.1 Sol 被需求打爆了，正在修。Sam 那边补了一句，说这是增长最快的模型，负载下有点慢，现在应该好多了。这些说法都能在 @Codexr 的推文里找到原话。

但用户的体感不太买账。@NFT_Chen 自己做了实测：Codex 里 GPT-6.1-Sol 只有 22 t/s，开了 Fast 也只有 46，直连 API 是 73。他顺带对比了一下，说 Anthropic 那边几乎不这么砍。另一边 @Pluvio9yte 转了个 Reddit 帖，意思是有人证明了 GPT 系列降速，很多人以为模型「变耐用了」，其实不是用量少了，只是处理变慢了。

这事我没法替谁下结论。只是觉得难受的地方在于：用户能感受到变化，却没法验证原因。厂商说一句「负载」，剩下的只能靠体感猜。这种信息不对称，比单纯的慢更让人不舒服。

顺着限速聊，自然就聊到性价比。@ai_funss 给了一组对比：同样是 20 美元，Claude Pro 给的是 30 亿 token 的 Opus 5.5（90 tps），ChatGPT Plus 给的是 8.7 亿 token 的 GPT-6.1-Sol（25 tps）。@xiaomovps 在开源节流，准备把 GPT PRO 降级，留 Claude Pro 和 GPT Plus，不够再考虑 OpenCode；他另算了一笔账，$10/月的 OpenCode 套餐平时用 DeepSeek Flash 加 GLM Flash，对不做前端的普通开发者够用。省不省其实因人而异，但大家开始认真比单价了，这本身就说明市场在从「尝鲜」转向「过日子」。

三、教程和工具：从 0 写 Agent，把 Office 塞进 Agent

@antiAIvo 准备开一个八期的系列教程，叫《从 0 手写一个 AI Agent》。第一期跑通最小 Agent，理解模型、工具和执行循环；第二期讲 Tool Calling，怎么定义工具、传参、执行、拿返回。这个路径挺扎实，比一上来就堆框架友好。

@mylifcc 提醒了一个很多人不知道的角落：Anthropic 悄悄上线了内部工程师的实战手记，里面从 Claude Code 的进阶技巧，到怎么写 Agent Harness、怎么搞 Context Engineering，都是官方的第一手经验。这类东西官方很少专门宣传，但信息密度往往比二手教程高。

DeepSeek 今天也放了个动作：把 dsh-libreoffice-kit 单独开源，拆出成 @deepseek-ai/libreoffice-kit，Node.js 直接调用，底层是一个裁剪版的 LibreOffice。说白了就是给 Agent 塞进一套自有的 Office 引擎，不再只是藏在 harness 里。

@goan9 还整理了 Codex 6.1 的六个「奇技淫巧」，第一条很实在：让它先问你，别急着写代码。他给的话术是「先问清楚目标用户、使用场景和验收标准，指出需求里的矛盾，整理方案后再实现」。做产品最烦的确实是页面做出来了，需求理解错了。另外 GitHubDaily 提到的 tradingview-mcp 也值得记一笔，它给 Claude、ChatGPT、Cursor 这些工具接上了实时行情数据，股票、加密、外汇、期货都能查，省得 AI 老拿几个月前的旧行情一本正经地分析。

四、最强的安全 AI，只握在少数人手里

@ScarletKc 提了个有点后背发凉的点：目前最强的网络安全 AI 只集中在几家公司手上。Anthropic 的 Mythos Preview 只给 Project Glasswing 里审核过的机构用，OpenAI 的 Daybreak Red 和 GPT-5.6-Cyber 也只开放给通过审批的企业，个人连申请入口都找不到。能力越强越需要管，这话没错，但管的方式是把门焊死还是设个门槛，结果会很不一样。

五、工具圈今天的新东西

MVT 手机取证和间谍软件检测工具，GitHub 上 15.1K star，安全团队开源，本地运行、免费无广告，支持 iOS 和安卓。能解析手机备份、做 ADB 实时扫描，查底层可疑痕迹。（@denziideng）

WeChatBridge 跑在 macOS 上的开源微信桥接工具，把微信能力封装成接口，对接各种 AI 和自动化工作流。本地私有部署，作者强调聊天数据不出本机。个人微信没有官方 API 这个老问题，算是又有人试了一条路。（@denziideng）

NVIDIA OpenShell 针对「不敢把 API key 交给 Agent」这个顾虑开源的沙箱。按 README 的说法，Agent 跑在受内核控制的隔离环境里，能访问的文件和系统调用都受限，外连也要走受控出口。

Cobalt 下载工具，GitHub 42.3K star，把各种平台的链接粘进去就能下，作者的说法是「从网上拿东西变得简单到离谱」。

jev-seo 开源 SEO 诊断工具。给一个首页网址，大约一分钟爬完整站，对照 Google 官方搜索文档的 52 条规则逐项查，robots.txt、sitemap、死链、重定向、canonical 都在里面。适合不想先花钱找人做诊断的人。（@NFTCPS）

户型装修工具 有人用一个 HTML 页面做了套装修设计工具，2D 平面图和 3D 场景都有。60 多种家具家电拖进去摆，贴墙自动吸附，非承重墙能拆，尺寸精确到毫米，一键切 3D，还能调日照时间。一个页面做到这个程度，确实有点意外。（@GitHub_D）

firebase-ios-sdk iOS 应用要的登录、崩溃统计、推送、云数据库，官方一个仓库全给了，6700 star、1797 fork，Apache 2.0 许可。（@Ryrenz）
