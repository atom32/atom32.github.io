Middle summary layer

From lesson mechanics to production reading

Use this layer between the runnable lab and the advanced anatomy chapters. Each row gives the teaching focus, the minimal mechanism, the production bridge, and a checkpoint question.

How to use it
  1. 1Open this page before a session to anchor the mental model.
  2. 2Use the checkpoint as the discussion question before live-coding.
  3. 3Jump from each glossary term when students need vocabulary before the advanced reading.
s01

The Agent Loop

Turn one model call into an agentic loop.

Open lessonSlides
Mental model

The model reasons, the harness acts, and the observation goes back into messages.

Lab mechanism

A while loop that sends messages, executes one bash tool, appends tool_result, and repeats.

Production bridge

The lab loop teaches tool_use and tool_result. QueryEngine keeps that kernel but adds streaming, usage accounting, retries, model fallback, and message normalization.

Checkpoint

Can you point to where Reason, Act, and Observe happen in the code?

GlossaryAgentic LoopReActtool_resultHarness Engineering
s02

Tools

Make capabilities extensible without changing the loop.

Open lessonSlides
Mental model

A tool is a contract between model intent and real-world execution.

Lab mechanism

Tool definitions, JSON input schemas, and a dispatch map from tool name to handler.

Production bridge

The dispatch map becomes a full Tool contract: schema validation, permission checks, concurrency flags, rendering, result storage, and sandboxed execution.

Checkpoint

Can you add one read-only tool and describe its schema, permission policy, and error shape?

GlossaryTool CallingDispatch MapSchemaPermission Boundary
s03

TodoWrite

Give the agent an inspectable planning surface.

Open lessonSlides
Mental model

Planning should be mutable state, not a private thought that disappears between turns.

Lab mechanism

TodoWrite stores tasks and injects reminders when the conversation drifts.

Production bridge

TodoWrite is a visible planning surface. In Claude Code, similar nudges arrive as attachments, plan-mode context, task reminders, and team coordination state.

Checkpoint

Can you explain when a todo reminder should enter messages, and when it should stay out?

GlossaryTodo StateContext AssemblyControl Plane
s04

Subagents

Delegate noisy work while keeping the parent context clean.

Open lessonSlides
Mental model

A subagent is context isolation plus a summary boundary.

Lab mechanism

Spawn a child with fresh messages, shared filesystem tools, and summary-only return.

Production bridge

The toy subagent uses independent messages. Production workers add backends, identity, task records, permission delegation, and completion notifications.

Checkpoint

Can you name what information should return to the parent and what should be discarded?

GlossarySubagentSummary LayerMailbox
s05

Skills

Load capability knowledge only when it is needed.

Open lessonSlides
Mental model

Discovery is cheap; full context is expensive.

Lab mechanism

Skill metadata is visible early; full SKILL.md content enters the conversation on demand.

Production bridge

SKILL.md loading becomes a layered extension architecture: discovery, command conversion, hook integration, plugin packaging, and dynamic context deltas.

Checkpoint

Can you separate the discovery prompt from the full operational instructions?

GlossarySkillPluginMCPHook
s06

Compact

Keep long work alive when the context window fills up.

Open lessonSlides
Mental model

Compact in layers: cheap and precise first, expensive and lossy last.

Lab mechanism

Micro-compact large tool results, auto-compact older turns, and archive full transcripts.

Production bridge

The lab's three layers map to microcompact, session-memory compact, and full LLM summaries, with API invariants, cache edits, thresholds, and circuit breakers.

Checkpoint

Can you choose what to preserve before asking an LLM to summarize?

GlossaryContext WindowCompactionSession MemorySummary Layer
s07

Tasks

Move goals from chat context into durable task state.

Open lessonSlides
Mental model

Long work needs a control plane outside the current prompt.

Lab mechanism

A file-backed task graph records dependencies, status, and next actions.

Production bridge

The task board is durable control-plane state. Claude Code extends that idea with JSONL sessions, parent chains, task variants, and background notifications.

Checkpoint

Can you replay task state after a crash without trusting the model memory?

GlossaryTask BoardControl PlaneEvent Log
s08

Background Tasks

Let slow work finish without blocking the next thought.

Open lessonSlides
Mental model

Background work is useful only if it has a reentry path.

Lab mechanism

Background threads run commands and send completion notifications back to the foreground loop.

Production bridge

A background thread and notification queue become task-state variants, completion XML, API priority rules, and foreground/background retry differences.

Checkpoint

Can you describe how the agent learns that background work is done?

GlossaryBackground TaskNotificationEvent Log
s09

Agent Teams

Coordinate multiple agents through durable messages.

Open lessonSlides
Mental model

Simple persisted mailboxes are often better than clever in-memory IPC.

Lab mechanism

Teammates exchange JSONL mailbox messages and preserve state across turns.

Production bridge

The JSONL inbox grows into a crash-safe mailbox with locks, team config, backend detection, leader-worker rules, and permission delegation.

Checkpoint

Can you prevent two workers from consuming or overwriting the same message?

GlossaryMailboxAgent SwarmPermission Boundary
s10

Team Protocols

Make team negotiation structured instead of ad hoc.

Open lessonSlides
Mental model

Every negotiation needs the same envelope: request, correlation id, response, timeout.

Lab mechanism

Request-response protocols use request_id to connect decisions across teammates.

Production bridge

The request-response pattern becomes structured control messages routed through SendMessage and reinforced by lifecycle hooks.

Checkpoint

Can you add a new protocol without changing the transport?

GlossaryProtocolHookMailbox
s11

Autonomous Agents

Let workers claim work autonomously while staying bounded.

Open lessonSlides
Mental model

Autonomy is polling plus ownership plus escape hatches.

Lab mechanism

Workers scan the board, claim available tasks, execute, and release or complete them.

Production bridge

Idle polling and task claiming become an autonomous worker loop backed by team context, mailbox polling, plan approval, and task notifications.

Checkpoint

Can you recover work when a worker dies after claiming a task?

GlossaryTask BoardLeaseAgent Swarm
s12

Worktree + Task Isolation

Separate the control plane from isolated execution lanes.

Open lessonSlides
Mental model

Tasks describe intent; worktrees provide safe directories to execute that intent.

Lab mechanism

Each task binds to its own worktree lifecycle and emits events back to the shared board.

Production bridge

Task/worktree binding turns intent into an isolated execution lane. Production adds backend-specific spawning, cleanup hooks, config propagation, and lifecycle telemetry.

Checkpoint

Can you identify which state belongs to the task and which belongs to the execution directory?

GlossaryWorktreeControl PlaneEvent Log
