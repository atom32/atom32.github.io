课程架构

双层 Agent Harness 课程

Learn Claude Code 提供实验室环境：12 个可运行机制。Claude Reviews Claude 提供真实系统解剖：同一批思想在生产复杂度下会如何展开。这张地图把每个教学机制连接到对应的真实子系统。

中间摘要

按 session 查看讲课重点、心智模型、实验机制、生产映射和检查点。

高级章节

进入真实系统解剖层，从 QueryEngine、工具系统和权限流水线开始读。

术语表

统一 Agent harness、tool calling、compaction、task board 等核心词汇。

第一层：实验室

一次只构建一个最小 harness 机制。每一节都足够小，适合运行、修改，并通过有控制的实验观察边界。

第二层：真实系统解剖

把同一个机制放回 Claude Code 中重新阅读，在那里流式、安全、持久化、团队协作和成本都会变成一等问题。

s01Agent 循环

一个模型如何靠一个循环和一个工具变成 Agent？

这个循环要面对真实用户，还需要补上什么？

实验室循环讲清 tool_use 和 tool_result。QueryEngine 保留这个内核，同时加入流式、用量统计、重试、模型降级和消息规范化。

练习: 给 s01 加一个最大轮次限制和一个极简重试包装，再对照 QueryEngine 的恢复矩阵。

s03TodoWrite

Harness 如何帮助模型在多步骤任务里保持意图？

提醒、计划和任务状态在真实对话里如何出现？

TodoWrite 是可见的规划表面。Claude Code 中类似信号会通过附件、计划模式上下文、任务提醒和团队状态注入。

s04子 Agent

子 Agent 如何把嘈杂工作隔离出主上下文？

真实 worker 如何生成、隔离、监督和汇总？

教学版子 Agent 使用独立 messages。生产 worker 还需要后端、身份、任务记录、权限委托和完成通知。

练习: 把每次子 Agent 请求和最终摘要写入 JSONL，让主 Agent 可以审计委派工作。

Skill、Plugin、MCP 工具和斜杠命令如何组成扩展系统？

s06上下文压缩

上下文满了以后，Agent 如何继续工作？

真实系统如何回收 token，同时尽量不破坏连续性和缓存价值？

实验室三层压缩对应微压缩、会话记忆压缩和完整 LLM 摘要，并进一步加入 API 不变量、cache edits、阈值和熔断器。

练习: 记录每一层压缩前后的 token 估算，并展示哪些内容被替换。
