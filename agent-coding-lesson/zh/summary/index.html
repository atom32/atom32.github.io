中间摘要层

从实验机制过渡到生产系统阅读

这一层放在可运行实验课和高级系统解剖之间。每一行给出讲课重点、最小机制、生产映射和检查点问题，方便 keynote、讲解和课后复盘。

怎么用
  1. 1每节课开始前先打开这一页，锁定本节课的心智模型。
  2. 2用检查点问题作为 live-coding 前的讨论题。
  3. 3学生缺术语时，直接跳到对应 glossary，再回来读高级章节。
s01

Agent 循环

把一次模型调用变成可持续行动的 Agent 循环。

打开课程幻灯片
心智模型

模型负责推理，harness 负责行动，观察结果再回到 messages。

实验机制

一个 while 循环：发送 messages，执行一个 bash 工具，追加 tool_result，然后继续。

生产映射

实验室循环讲清 tool_use 和 tool_result。QueryEngine 保留这个内核，同时加入流式、用量统计、重试、模型降级和消息规范化。

检查点

你能在代码里指出 Reason、Act、Observe 分别发生在哪里吗？

术语Agentic LoopReActtool_resultHarness Engineering
s02

工具使用

让新能力以可扩展方式接入，避免每增加一个工具就改写循环。

打开课程幻灯片
心智模型

工具是模型意图和真实世界执行之间的一份契约。

实验机制

工具定义、JSON input schema，以及从 tool name 到 handler 的 dispatch map。

生产映射

dispatch map 在真实系统里会长成完整 Tool 契约：schema 校验、权限检查、并发标志、结果存储和沙箱执行。

检查点

你能新增一个只读工具，并说明它的 schema、权限策略和错误形状吗？

术语Tool CallingDispatch MapSchemaPermission Boundary
s03

TodoWrite

给 Agent 一个用户可检查的规划表面。

打开课程幻灯片
心智模型

计划应该成为可更新、可检查的状态，能够在多个轮次之间持续存在。

实验机制

TodoWrite 存储任务，并在对话开始漂移时注入提醒。

生产映射

TodoWrite 是可见的规划表面。Claude Code 中类似信号会通过附件、计划模式上下文、任务提醒和团队状态注入。

检查点

你能解释 todo 提醒什么时候该进入 messages，什么时候不该进入吗？

术语Todo StateContext AssemblyControl Plane
s04

子 Agent

把嘈杂工作委派出去，同时保持主上下文干净。

打开课程幻灯片
心智模型

子 Agent 本质上是上下文隔离加摘要边界。

实验机制

生成一个 fresh messages 的子进程/子 Agent，共享文件系统工具，只把最终摘要返回给父 Agent。

生产映射

教学版子 Agent 使用独立 messages。生产 worker 还需要后端、身份、任务记录、权限委托和完成通知。

检查点

你能说清楚哪些信息该返回父 Agent，哪些应该被丢弃吗？

术语SubagentSummary LayerMailbox
s05

技能

只在需要时加载能力知识。

打开课程幻灯片
心智模型

发现信息很便宜，完整上下文很昂贵。

实验机制

先暴露 skill metadata，只有按需时才把完整 SKILL.md 放进对话。

生产映射

SKILL.md 加载在真实系统里会变成分层扩展架构：发现、命令转换、Hook 集成、插件打包和动态上下文增量。

检查点

你能把发现提示和完整操作说明分开吗？

术语SkillPluginMCPHook
s06

上下文压缩

当上下文窗口被填满时，让长任务继续活下去。

打开课程幻灯片
心智模型

压缩要分层：先便宜精准，最后才昂贵有损。

实验机制

微压缩大型工具结果，自动压缩旧轮次，并归档完整 transcript。

生产映射

实验室三层压缩对应微压缩、会话记忆压缩和完整 LLM 摘要，并进一步加入 API 不变量、cache edits、阈值和熔断器。

检查点

你能在让 LLM 摘要前先决定哪些信息必须保留吗？

术语Context WindowCompactionSession MemorySummary Layer
s07

任务系统

把目标从聊天上下文移到持久任务状态里。

打开课程幻灯片
心智模型

长任务需要一个独立于当前 prompt 的控制平面。

实验机制

文件化任务图记录依赖、状态和下一步行动。

生产映射

任务板是持久控制平面。Claude Code 把这个想法扩展到 JSONL 会话、父链、任务变体和后台通知。

检查点

你能在崩溃后不依赖模型记忆来重放任务状态吗？

术语Task BoardControl PlaneEvent Log
s08

后台任务

让慢操作继续执行，同时不阻塞 Agent 的下一步思考。

打开课程幻灯片
心智模型

后台工作只有在能重新进入对话流时才有价值。

实验机制

后台线程执行命令，并把完成通知送回前台循环。

生产映射

后台线程和通知队列会扩展为任务状态变体、完成 XML、API 优先级规则，以及前台/后台不同的重试策略。

检查点

你能描述 Agent 如何知道后台工作已经完成吗？

术语Background TaskNotificationEvent Log
s09

Agent 团队

通过持久消息协调多个 Agent。

打开课程幻灯片
心智模型

当 Agent 是独立工作者时，简单持久邮箱常常比聪明的内存 IPC 更可靠。

实验机制

队友通过 JSONL 邮箱交换消息，并跨轮次保留状态。

生产映射

JSONL inbox 会长成带锁的崩溃安全邮箱、团队配置、后端检测、领导-工人规则和权限委托。

检查点

你能防止两个 worker 消费或覆盖同一条消息吗？

术语MailboxAgent SwarmPermission Boundary
s10

团队协议

把团队协商定义为结构化协议，减少临时话术带来的歧义。

打开课程幻灯片
心智模型

每次协商都需要同一种信封：request、correlation id、response、timeout。

实验机制

request-response 协议用 request_id 关联队友之间的决策。

生产映射

request-response 模式在真实系统中会变成结构化控制消息，由 SendMessage 路由，并由生命周期 Hook 强化。

检查点

你能在不改 transport 的情况下新增一种协议吗？

术语ProtocolHookMailbox
s11

自主 Agent

让 worker 自主认领任务，同时保持边界。

打开课程幻灯片
心智模型

自主性 = 轮询 + 所有权 + 逃生通道。

实验机制

worker 扫描任务板，认领可用任务，执行，然后释放或完成。

生产映射

idle polling 和 task claiming 会变成由团队上下文、邮箱轮询、计划审批和任务通知支撑的 worker 循环。

检查点

worker 认领任务后挂掉时，你能恢复这项工作吗？

术语Task BoardLeaseAgent Swarm
s12

Worktree + 任务隔离

把控制平面和隔离执行通道分开。

打开课程幻灯片
心智模型

任务描述意图，worktree 提供安全的执行目录。

实验机制

每个任务绑定自己的 worktree 生命周期，并把事件发回共享任务板。

生产映射

task/worktree 绑定把意图变成隔离执行通道。生产系统还会加入后端生成、清理 Hook、配置传播和生命周期遥测。

检查点

你能区分哪些状态属于任务，哪些属于执行目录吗？

术语WorktreeControl PlaneEvent Log
