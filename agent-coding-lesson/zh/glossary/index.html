Agent Swarm

定义

由共享状态、协议和监督协调的一组 Agent worker。

为什么重要

它让一个 assistant 变成多个有边界的工作通道。

出现课程
s09Agent 团队s11自主 Agent

Agentic Loop

agent loop

定义

模型选择行动、harness 执行动作、结果回到上下文的重复循环。

为什么重要

这是把模型变成 Agent 的最小结构。

出现课程
s01Agent 循环

Background Task

定义

在前台 Agent 轮次之外继续执行，并通过通知或结果重新进入的工作。

为什么重要

它避免慢操作冻结推理循环。

出现课程
s08后台任务

Compaction

定义

把旧的或庞大的上下文替换成更小表示，同时保留连续性。

为什么重要

它控制 token 成本，并防止模型淹没在过期细节里。

出现课程
s06上下文压缩

Context Assembly

定义

每一轮决定哪些 system prompt、记忆、附件、提醒和状态进入模型调用的过程。

为什么重要

同一份状态在不同时间进入上下文，可能是帮助，也可能是干扰。

出现课程
s03TodoWrites05技能s06上下文压缩

Context Window

定义

一次模型调用能容纳的文本和结构化内容上限。

为什么重要

每个长时间运行的 Agent 最终都会变成上下文管理问题。

出现课程
s06上下文压缩

Control Plane

定义

决定有哪些工作、谁拥有它、进展如何记录的状态与协调层。

为什么重要

它让执行通道变化或失败时，目标仍然稳定。

Harness Engineering

agent runtime

定义

围绕模型搭建可执行系统的工程：messages、工具契约、执行、权限、上下文、重试、日志、任务和恢复。

为什么重要

许多 Agent 质量问题首先是运行时设计问题，其次才是提示词问题。

Hook

定义

在工具、会话或通知之前、之后或周围运行的生命周期拦截点。

为什么重要

Hook 让策略和自动化可以挂到 harness 上，而不用重写核心循环。

Lease

定义

对任务或资源的限时所有权声明。

为什么重要

它让 worker 消失后，被遗弃的工作可以重新被认领。

为什么重要

MCP

Model Context Protocol

定义

把外部工具和资源暴露给模型驱动客户端的一种协议。

为什么重要

它让工具生态可以跨客户端复用，避免绑定在单一应用实现中。

Notification

定义

告诉 Agent 或 UI 外部工作状态发生变化的结构化信号。

为什么重要

决定某个请求动作是否允许执行的策略边界。

为什么重要

ReAct

Reason-Act-Observe

定义

一种循环模式：先推理下一步，通过工具行动，观察结果，然后继续。

为什么重要

它给学生一个阅读 tool_use 和 tool_result 轨迹的基本词汇。

为什么重要

tool_result

定义

工具执行后，把输出返回给模型的结构化观察消息。

为什么重要

Worktree

定义

隔离的 checkout 或目录通道，让一个任务可以修改文件而不和另一个通道冲突。

为什么重要

它让并行 Agent 获得文件系统隔离，而不必复制整个仓库。
