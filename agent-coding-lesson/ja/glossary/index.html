Agent Swarm

定義

A team of agent workers coordinated by shared state, protocols, and supervision.

重要性

It is how one assistant becomes multiple bounded work lanes.

Agentic Loop

agent loop

定義

The repeated cycle where the model chooses an action, the harness executes it, and the result is fed back into context.

重要性

It is the smallest structure that turns a model into an agent.

関連セッション

Background Task

定義

Work that continues outside the foreground agent turn and later reenters through a notification or result.

重要性

It prevents slow operations from freezing the reasoning loop.

Compaction

定義

Replacing old or bulky context with smaller representations while preserving continuity.

重要性

It controls token cost and prevents the model from drowning in stale details.

Context Assembly

定義

The per-turn process of deciding which system prompts, memories, attachments, reminders, and state enter the model call.

重要性

The same state can help or distract depending on when it enters context.

Context Window

定義

The limited amount of text and structured content that can fit into one model call.

重要性

Every long-running agent eventually becomes a context management problem.

関連セッション

Control Plane

定義

The state and coordination layer that decides what work exists, who owns it, and how progress is recorded.

重要性

It keeps goals stable while execution lanes change or fail.

Dispatch Map

定義

A lookup table from tool name to the handler that executes that tool.

重要性

It lets the loop stay stable while capabilities grow.

Event Log

An append-only record of meaningful state transitions and observations.

重要性

It supports replay, debugging, audit, and recovery after crashes.

Harness Engineering

agent runtime

定義

The engineering around the model: message structure, tool contracts, execution, permissions, context, retries, logs, tasks, and recovery.

重要性

Most agent quality problems are runtime design problems before they are prompt problems.

Hook

定義

A lifecycle interception point that runs before, after, or around tools, sessions, or notifications.

重要性

Hooks let policy and automation attach to the harness without rewriting the core loop.

Lease

重要性

It lets abandoned work become claimable again after a worker disappears.

MCP

Model Context Protocol

定義

A protocol for exposing external tools and resources to model-driven clients.

重要性

It makes tool ecosystems portable across clients instead of hard-wired into one app.

関連セッション

Notification

定義

A structured signal that tells the agent or UI that external work changed state.

重要性

Without notifications, background work finishes silently and is easy to miss.

Permission Boundary

定義

The policy layer that decides whether a requested action may execute.

重要性

Agent systems need useful power without giving every model output unrestricted authority.
